## 6. 缺陷与处理

| 编号 | 问题 | 原因 | 处理结果 |
|---|---|---|---|
| DEF-01 | 全量报告旧版误判失败 | 要求所有真实脏数据100%通过清洗 | 改为验证处理闭环、唯一接受资产和哨兵零拒绝 |
| DEF-02 | 10次哨兵被治理层拒绝 | 模拟增长场景分配给高技能密度岗位 | 加法型场景确定性分配给低密度技能画像，预检归零 |
| DEF-03 | 视觉配置占位符被视为有效 | 客户端只检查非空 | 增加占位值识别；真实视觉配置已验证 |
| DEF-04 | 简历文本请求长时间无输出 | 14秒重试及错误变量提示不准确 | 增加简历专用60秒超时、独立零重试和正确提示 |
| DEF-05 | DeepSeek结构化简历返回空内容 | 默认思考耗尽全部输出Token；旧 `enable_thinking` 字段无效 | 按DeepSeek官方格式发送 `thinking.type=disabled` |
| DEF-06 | 文本简历模型不适配复杂JSON提示 | Pro模型产生过长推理 | 增加简历专用模型来源，使用Flash Vision处理简历语义 |
| DEF-07 | 报告结束时GBK打印失败 | 完整报告包含控制台无法编码字符 | 控制台只输出ASCII安全摘要，UTF-8完整报告写文件 |
| ENV-01 | Docker引擎无响应 | Docker Desktop/WSL后端卡死 | 重置Docker专用WSL与Desktop，会话恢复为running |

## 7. 风险、限制与后续项

1. 模拟月份用于验证变化捕捉能力，不代表未来真实招聘市场趋势。
2. 380条真实语料治理拒绝应作为数据质量改进样本人工抽查，不应直接放宽清洗规则。
3. 当前源码全量 pytest 已在隔离 API 镜像中无中断完成（139 passed）；前端生产构建亦已通过。
4. 图片简历质量仍受分辨率、页面方向、复杂表格和视觉模型服务稳定性影响，应保留失败重试与人工上传文字版入口。
5. `.env` 含真实密钥且已被Git忽略，禁止将其复制进源码、日志、报告或提交记录。
