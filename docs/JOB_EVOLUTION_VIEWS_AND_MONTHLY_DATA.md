# 岗位演进双视图与月度测试数据改动说明

> 本文记录历史测试或开发结果；本机路径已统一为 `<project-root>`（仓库根目录），不代表在当前设备重新执行。历史运行产物未随源码发布。

## 一、改动目标

本次开发在不修改后端知识图谱接口、不影响原有二维关系和三维时间图谱功能的前提下，补充岗位技能栈演进研究能力，并将研究演示时间统一为 `2025-09` 至 `2026-08`。

## 二、主要功能改动

### 1. 二维岗位演进

- 在二维关系图中新增岗位演进模式，沿用 Cytoscape 的拖动、缩放、悬停邻域高亮、节点点击锁定和空白处取消选择逻辑。
- 支持两个精选研究岗位：
  - `AI Agent 应用开发工程师（新兴岗位演示数据）`
  - `Java开发工程师（既有岗位演示数据）`
- 岗位节点位于演进网络中心，技能节点按双环结构分布；拖动时间轴时，岗位名称、技能加入、增强、减弱和退出状态同步变化。
- 调整岗位与技能节点的视觉比例：缩小中心岗位节点，放大技能节点，并以带名称、状态色和辉光的圆角说明框呈现技能。
- 演进研究面板移至左侧，二维画布预留相应空间；右侧岗位详情卡保持独立区域，避免面板相互遮挡。

### 2. 三维岗位演进

- 保留 `AI Agent 应用开发工程师` 为默认精选岗位。
- 新增 `Java开发工程师（既有岗位演示数据）`，使用与二维视图一致的月份、岗位称呼和技能变化口径。
- 两个精选岗位共享统一演进定义，避免二维与三维展示结果不一致。
- 原有其他真实岗位仍可在三维岗位演进模式中搜索和查看，不影响现有虫洞时间图谱、黄道面及关系视图。

### 3. 搜索与界面交互

- 岗位演进搜索框新增固定搜索历史，两个精选岗位不会被“清空其他记录”操作删除。
- 搜索框支持在已经获得焦点的情况下重复点击并再次呼出搜索历史。
- 搜索历史展开时自动隐藏“可见关系”统计栏，关闭历史后恢复，避免两层界面重叠。
- 二维演进模式下隐藏重复时间戳，将月份与技能变化集中显示在研究面板和时间轴中。

## 三、时间数据与测试集调整

- 将岗位演进与全量测试数据时间范围统一为 `2025-09` 至 `2026-08`，共 12 个月。
- 删除旧的 13 个月原始测试文件。
- 删除旧的 `2026-09` 至 `2027-08` 月度批次。
- 新增 `2025-09` 至 `2026-08` 月度批次、对应清单、基线、真值与测试报告。
- 真实证据不足的月份只用于确定性研究演示，并在界面中标记为模拟或推断，不作为现实岗位趋势预测。
- 本次数据调整仅涉及 `temporal_progression_test` 测试数据，不删除或修改真实岗位数据库。

## 四、兼容性说明

- `.env`、模型密钥、真实数据库和本地回滚备份均未纳入提交。
